# Q版戰棋 Phaser 原型與遷移計畫

`proto/phaser/index.html`：桶狹間地圖，用 Phaser 4 重畫，正式版 `slg.html` 完全沒動。

## 原型示範了什麼

- 美術沿用正式版自己畫的 SVG（`slg/iso.js` 地圖、`slg/chibi.js` 武將），音效沿用 `slg/audio.js`，所以不需要任何外部素材就能跑。
- Phaser 負責的部分：
  - 鏡頭：拖曳平移、滾輪與雙指縮放；開戰時鏡頭推近、結束拉回。
  - 粒子：紅葉飄落、豪雨（含閃電）、本陣篝火、水面閃光、雲影飄過。
  - 戰鬥演出：戰法 cut-in（斜帶滑入、武將大頭、戰法名、掃光）、衝鋒與擊退、刀光、火花、閃白、鏡頭震動、彈出傷害數字、兵力條殘影、潰走煙塵。
  - 鏡頭濾鏡：暗角；「移軸」按鈕開模型沙盤的景深感（比較吃效能，預設關）。
  - 選取部隊時發光、移動範圍與攻擊目標格閃爍、走格子時小跳步。
- **傷害是示意亂數**，不是 `slg/engine.js` 的戰鬥公式；敵軍 AI 只有「往最近的我方走、射程內就打」。

## 為什麼選 Phaser（不選 Godot）

| | Phaser 4 | Godot 4 網頁輸出 |
| --- | --- | --- |
| 現有程式 | `engine.js`、`scenarios.js`、`bingaku.js`、`audio.js`、`iso.js`、`chibi.js` 直接沿用 | 全部要用 GDScript 重寫 |
| 頁面大小 | 引擎約 1.4 MB | 引擎 wasm 數十 MB，手機首次開啟慢 |
| 設定、組隊、戰報等網頁介面 | 保留現在的 HTML，只把戰場換成 Phaser 畫布 | 要在 Godot 裡重做或和網頁溝通 |
| 部署 | 照舊放 GitHub Pages | 需要額外設定（SharedArrayBuffer 標頭等） |

## 分批遷移（每批一個 PR，Joe 看過再進下一批）

1. **戰場換成 Phaser 畫布**：`slg.html` 的 `#board`（現在是 SVG）改成 Phaser；設定頁、資訊欄、戰況、對話框維持 HTML。規則、AI、存檔都不動。先用網址參數 `?engine=phaser` 切換新舊版，兩版並存，Joe 確認後才變預設。主要改 `slg/game.js` 的 `renderBoard` 與點擊處理。
2. **戰鬥視窗演出**：把 `#bt` 戰鬥對話框換成 Phaser 戰鬥場景，用 `engine.battle()` 產生的 8 回合紀錄逐回合播動畫（cut-in、數字、兵力條），數字與現在完全一致。
3. **換素材**：拿到 CC0 素材後，替換粒子、介面框、音效；每一項記到 `/CREDITS.md`。
4. **收尾**：移除舊 SVG 戰場的程式碼、調手機效能（低階手機自動關濾鏡）。

風險與對策：

- 手機效能：濾鏡（移軸、發光）在低階手機可能掉幀，預設只開暗角，其他可關。
- 點擊判定：地塊是斜的、武將會蓋到後面的格子；原型已用「先判定武將，再判定菱形格」處理。
- 新舊兩版並存期間，改規則只改 `engine.js` 一處，兩版都會吃到。
