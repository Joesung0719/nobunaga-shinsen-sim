# 先定位再配點／兵學（Joe 四隊思路，2026-11-23）

程式：`slg/playbook.js`（規則）、`slg/advisor.js`（接進兵學／配點建議）、`tools/joe-plan-eval.mjs`（回測）。全部由戰法說明文字與能力判斷，不寫死人名。

## 決策順序（每位武將）
1. **看戰法組成**（固有＋兩招＋兵種技）：持續傷害、控制（封擊／威壓／麻痺…）、補血、減傷／護盾／被打觸發、突擊、傷害戰法數。
2. **配點**
   - 減傷／護盾戰法 ≥2 且統率不輸輸出屬性 → 統率（氏康）。
   - 戰法效果多受統率影響且統率最高 → 統率（隆信）。
   - 指揮技是兵謀，且武勇、智略相差 15% 內，且沒有「造成某類傷害就自己加另一屬性」的戰法 → 各點一半（政宗）。
   - 其他 → 戰法「受X影響」與傷害類型票數最高者，同票看原始能力（光秀智略、道雪武勇、信玄智略）。
3. **兵學方向**（分數最高者）：補血 ≥2、或沒有傷害戰法的輔助 → 臨戰；持續傷害／控制 → 機略；減傷、被打觸發、統率明顯最高、或隊友提供護盾 → 陣立；突擊輸出 → 武略。
4. **奇節點**：機略有持續傷害→詭計百出，有控制→軍律擾亂；臨戰補血≥2→鼓舞奮迅，有控制→掎手之策；陣立有被打觸發→先陣誘敵，否則反討之計；武略有突擊→虛實自在。
