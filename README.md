# 真戰登用模擬器

《信長之野望 真戰》的抽卡（登用）模擬網頁，純前端、免安裝，用 GitHub Pages 就能直接開。

## 功能

- 兩個卡池：**S1初始大卡池**、**PK賽季武將**（UP：石川數正、島津義久、龍造寺隆信、吉岡妙林）
- 1次登用／5次登用，30 抽保底 5★，每 5 抽必得 4★ 以上（額外贈送）
- 動畫依實機流程自製（Canvas 繪製，不使用官方影片）：登用開場（家徽飄落、雲、白光）、卡背飛入後依序翻牌，4★ 發紫光；5★ 必有閃電，首次獲得再加光爆、家徽登場與武將登場畫面，重複只有閃電
- 登用紀錄表（可依星級篩選）、統計、已獲得名將
- 機率可在頁面上調整；紀錄存在瀏覽器的 localStorage

## 機率來源

S1初始大卡池使用官方〈機率公告〉（2025-08-29，臺港澳新馬版）：

| 星級 | 合計 | 武將數 | 個別機率 |
| --- | --- | --- | --- |
| 5★ | 5.60% | 42 | 0.06% / 0.08% / 0.16% |
| 4★ | 36.00% | 40 | 0.90% |
| 3★ | 58.40% | 17 | 3.44% |

PK賽季卡池沒有公開機率：星級機率比照 S1，UP 武將權重 ×6（依活動文字「最大6倍」推估），S1 沒有的 5★ 以 0.16% 為基準。

## 檔案

- `index.html`：整個頁面（HTML、CSS、JS）
- `data.json`：142 名武將（名稱、星級、Cost、勢力、S1 個別機率 `s1`）
- `img/c###.webp`：武將卡圖，`img/k###.webp`：5★ 武將的家徽（裁自卡圖左下角）
- `tools/crop_cards.py`：從遊戲「一覽」截圖裁切武將卡的腳本

## 本機執行

`data.json` 是用 `fetch` 讀取的，所以要用本機伺服器開，不能直接雙擊 HTML：

```sh
python3 -m http.server 8000
# 開啟 http://localhost:8000
```
